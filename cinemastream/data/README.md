# CinemaStream data

These CSVs are the **canonical sample dataset** for the book. They are **committed
fixtures** — every chapter and notebook reads them, so the book is reproducible at
any entry point (clone the repo, or run the setup cell in any Colab notebook).

## Do not hand-edit these files

They are generated by a single seeded script:

```bash
python cinemastream/scripts/generate_data.py
```

Running it reproduces these exact files (deterministic, `seed = 42`). A CI check
(`tools/check_data_contract.py`) fails if a committed CSV drifts from the generator.
