# =============================================================================
# CinemaStream Handbook — pinned dependencies for reproducible runs
# =============================================================================
# Install everything:        pip install -r requirements.txt
#                        OR  uv pip install -r requirements.txt   (recommended — faster, catches conflicts)
# Supported Python: 3.11, 3.12, or 3.13 (tested on 3.13.7). NOT 3.14 — the
# pinned compiled wheels (torch, faiss, duckdb, catboost, …) lag new Python
# releases and would fall back to failing source builds. See SETUP.md Step 4.
# Pinning makes runs reproducible on Windows, macOS, Linux, and Google Colab,
# and prevents breakage when a library ships a breaking major release
# (e.g. transformers 5.x removed the "summarization" pipeline task alias).
#
# NOTE on transformers: pinned <5 on purpose. The book teaches the canonical
# pipeline("summarization") / pipeline("translation") API, which lives in 4.x.
#
# NOTE on platform-specific packages:
#   - vllm (Ch 128) requires Linux + CUDA; it is intentionally NOT listed here.
#     Install separately on a GPU Linux box: pip install vllm
#   - faiss-cpu ships wheels for Windows/macOS/Linux incl. Apple Silicon.
#   - duckdb: install the wheel (pip install duckdb), not from source on Windows.
# =============================================================================
